# Lumina Monsters

A browser tower defense game: raise monsters, fuse them into new ones, and defend your carriage.

- 75 monsters, each with its own active skill and effect
- 5-chapter story, Arena, Endless mode
- Online leaderboards
- English / Japanese
- Made for phones in portrait mode (works on PC too)

## How to play
Open `index.html` in a browser (or play on itch.io).

## Built with
- HTML5 Canvas + JavaScript (single file)
- three.js r128 (MIT License) for 3D monster models
- Music and sound effects generated with code
