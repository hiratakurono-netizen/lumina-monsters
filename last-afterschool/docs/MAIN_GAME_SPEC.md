# 本編 詳細設計（第2段階・確定版 v1）

`MAIN_GAME_PLAN.md`（調査と設計案）を土台に、決定事項を反映した仕様です。
「（仮）」は、プレイテストで調整する前提の値です。

## 0. 決定事項
| 項目 | 決定 |
|---|---|
| 倒れた時 | その潜入で**入手したゴールドの1/3を失う**。拾った装備・アイテムは失わない |
| 帰還 | **5階・10階の出口**で帰還できる＋**帰還アイテム**（いつでも使える消耗品） |
| 途中再開 | 5階をクリアすると、次回から**6階から開始**できる |
| 武器の種類 | 草原まではバット系・椅子系・机系の3系統 × 性能違い。草原の完成後に新しい武器デザインを作る |
| 防具 | 見た目は変えず、性能だけ |
| 現世 | **歩き回れる町**（施設に入る・人に話しかける） |
| 厳しさ | 砂漠：水1本で約2分。火山：各階3分 |
| 顔アイコン | 今の6表情のまま |

## 1. 画面の流れ
```
タイトル ─ はじめから → プロローグ（STAGE1〜5・変更なし）→ 現世の町
        └ つづきから（本編開始後に表示）→ 現世の町
現世の町 ─ 屋上のゲート → ダンジョン選択（開始階：1階 / 6階）→ 魔界
魔界 n階 ─ 出口 → n+1階 …
        ├ 5階・10階の出口：「帰還する／先へ進む」（10階はボス撃破で帰還）
        ├ 帰還アイテム：いつでも現世へ
        └ 倒れる：入手ゴールドの1/3を失って現世へ
```

## 2. 現世の町（歩き回れる）
- 横スクロールの町（約3画面分）。操作はダンジョンと同じ（歩く・走る・ジャンプ）。戦闘はしない。
- 施設・人に近づくと「しらべる」が出る（キー：↓／E、スマホ：画面の「しらべる」ボタン）。
- 施設とメニュー（メニューは HTML 部品を重ねて表示。指で押しやすい大きさ）

| 場所 | できること |
|---|---|
| 自宅 | セーブ、装備変更、持ち物、ステータス、セーブの書き出し／読み込み |
| コンビニ | 回復アイテム・水・冷却材・帰還アイテムの購入、売却 |
| 学校の屋上（ゲート） | ダンジョンと開始階を選んで出発 |
| 友人（ミオ） | 会話（進行に応じてセリフが変わる。将来のイベントの入口） |
| 鍛冶屋（将来） | 強化・分解（建物だけ置いて「準備中」） |

施設・人は「場所データ」の配列で定義し、追加しやすくする。

## 3. 魔界ダンジョン
- 1階 ＝ 横に長いマップ（6〜10部屋分、深いほど長い）。左から入り、右端の出口へ。
- 縦方向は1画面に収まる高さ（カメラは横だけ動く。スマホで見やすさ優先）。
- 5階：中ボス。10階：ダンジョンのボス。
- HP・MP は階をまたいで引き継ぐ。5階の中ボスを倒すと全回復（仮）。
- 穴に落ちると：最大HPの15%のダメージ（仮）で、直前に立っていた足場へ戻る。

### 3-1. 生成（草原で最初に作る）
1. ダンジョンごとに「部屋パーツ」（幅 960〜1920）を用意。種類：平地の戦闘部屋／段差／足場渡り／穴越え／高台の宝箱／隠し部屋の入口／休憩（敵なし）／中ボス部屋／ボス部屋／出口。
2. 階ごとのルール（長さ・敵の数・宝箱の数・パーツの出やすさ）で乱数を使って並べる。
3. パーツの中の「置ける場所の候補」から、敵・宝箱・アイテム・環境オブジェクトを乱数で置く。
4. 保証：
   - パーツごとに「そのダンジョンのジャンプ力で通れる」ことを自動チェック
   - 並べた後、足場の到達可能性を計算して、出口まで行けなければ作り直す
   - 開発用の自動テストで数百シードを検査
5. 乱数はシード値で再現できる（不具合の階をそのまま再現できる）。

## 4. 装備・アイテム
### 4-1. 装備枠
武器3枠（今の Q 切り替えをそのまま）＋ 防具1枠 ＋ アクセサリー2枠

### 4-2. アイテムのデータ
- **元データ**（種類ごと）：`{ id, name, kind: weapon|armor|accessory|consumable|material, type: bat|chair|desk（武器）, base: { atk / def / hp …}, price, minFloor }`
- **個体データ**（拾った1個ごと）：`{ uid, base, rarity, plus, affixes: [{ k, v }], element }`
- 消耗品・素材は「種類と個数」だけを持つ（同じ物は重ねる）。

### 4-3. レアリティ（仮）
| | 色 | 付与効果の数 | 出始める目安 |
|---|---|---|---|
| コモン | 白 | 0 | 1階〜 |
| アンコモン | 緑 | 1 | 1階〜 |
| レア | 青 | 2 | 3階〜 |
| エピック | 紫 | 3 | 草原後半・砂漠〜 |
| レジェンド | 金 | 3＋固有効果 | 火山・魔王城（草原ボスでまれに） |

武器はレアリティ色のオーラで光らせる（見た目の違いの代わり）。

### 4-4. 付与効果（最初に作る分）
攻撃力+ ／ 攻撃速度+ ／ 会心率+ ／ 最大HP+ ／ 防御+ ／ 移動速度+（重さを軽減）／ 属性付与（砂・炎）／ HP吸収 ／ 必殺のMP消費軽減。
効果は「名前・数値の範囲・効く場所」を1か所の表で定義し、後から増やせるようにする。

### 4-5. 所持品
- 装備品：最大30個（仮）。いっぱいの時は拾えず「持ち物がいっぱい」と表示。
- 消耗品：種類ごとに最大9個（仮）。戦闘中は「アイテム」ボタンで使う。

## 5. ステータス
- 最大HP ＝ 100 ＋ 8×(Lv−1) ＋ 装備
- 攻撃 ＝ 武器の攻撃力 ×（1 ＋ 0.08×(Lv−1)）× 付与効果（今の倍率計算を広げる）
- 被ダメージ ＝ 敵の攻撃 × 100 ÷（100 ＋ 防御）
- 会心率：基本10%（今と同じ）＋ 装備

## 6. ドロップ
- ゴールド：ほぼ全ての敵が少量。
- 装備：通常の敵はまれ、エリートは高め、中ボス・ボスは確定。
- 宝箱：各階 1〜3個。隠し部屋の宝箱は1段階上のレアリティが出やすい。
- 「周囲の物で属性」：たき火・サボテンなどの環境オブジェクトに触れる／叩くと、今の武器に一時的な属性（30秒・仮）。敵が落とす武器（骸骨の剣など）は砂漠以降。

## 7. セーブ v2
```js

```

- 書き出し／読み込み（文字列をコピー）を自宅のメニューに置く（iOS のデータ消失対策）。
