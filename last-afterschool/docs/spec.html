5. 魔界ダンジョン

5-1. 共通ルール

  • 各階は手作りの部屋パーツを乱数で並べて生成（平地・段差・穴・丘・足場渡り・寄り道・キノコばね・戦闘部屋）。出口まで到達できるか自動チェックし、だめなら作り直す
  • 5階：中ボス（倒すとHP全回復・帰還か続行を選ぶ・次回から6階開始可）、10階：ボス（踏破で次のダンジョン解放）
  • 帰還：5階・10階の出口、または帰還の鈴。倒れた時：その潜入で拾ったゴールドの1/3を失う（装備・道具は失わない）
  • 難しさは「深さ」（草原1〜10 … 魔王城41〜50）で決まる：敵のHP・攻撃、ドロップのレアリティ、ショップの品ぞろえ
  • 穴に落ちると最大HPの15%のダメージで直前の足場へ

5-2. ダンジョンごとの特徴

ダンジョン環境ルール・仕掛け5階ボス10階ボス（攻略の鍵）
草原制限なし。たき火（炎30秒）、草むら、キノコのばね草原の主 オオカミ苔むした巨像（苔の鎧を炎で焼く。部屋にたき火）
砂漠水分ゲージ（水1本約2分）→ 熱中症3段階。オアシス、サボテン（叩くと砂属性）砂の女王 オオサソリ砂に眠る巨人（砂の槍）
雪原ジャンプ力約75%、氷の床（滑る）、深雪（60%）、氷晶（叩くと氷属性）氷牙の狼王霜竜（氷の鎧を炎で溶かす）
火山各階3分の制限時間（敵撃破+2秒・冷却材+30秒・冷気の噴出口+15秒）。時間切れでHP減少、溶岩だまり炎の死神溶岩の巨像（溶岩の鎧を氷で冷やす）
魔王城1〜5階は外郭（深淵の裂け目）、6〜10階は城内（燭台で炎）。敵の強さ中心動く城門魔王（結界は炎か氷で破る。HP半分で闇の弾と近衛騎士）

7. 装備・成長・ドロップ

  • 装備枠：武器3・防具1・アクセサリー2。所持品は装備30個まで、消耗品は種類ごとに上限
  • レアリティ5段階（コモン → アンコモン → レア → エピック → レジェンド）。付与効果：攻撃力・攻撃速度・会心・HP・防御・移動・HP吸収・必殺MP軽減・属性
  • ドロップ：通常の敵7%、宝箱50%、隠し宝箱は必ず（アンコモン以上）、5階ボス2個、10階ボス2個（レア以上・15%でレジェンド）
  • 成長：レベルで最大HPと攻撃が上がる。必要経験値 20＋10×Lv＋6×Lv²、レベルアップで最大HPの10%回復
  • 消耗品：いちごミルク・お弁当・水・冷却材・帰還の鈴・力のキャンディ（その潜入中 攻撃+20%）
  • セーブ：ブラウザに自動保存（v2・旧データ自動移行）。書き出し／読み込みで端末の消失に備える

9. 今後実装すると面白くなりそうなアイデア

9-1. ハクスラの中毒性

  • 鍛冶屋の強化 +1〜+10：ダンジョンの素材と組み合わせ、+7以上で見た目が光る。分解で素材に戻せる
  • レジェンド固有効果：「3コンボ目が必ず会心」「ガード成功で衝撃波」など、遊び方が変わる効果
  • セット装備：同じダンジョンの装備を揃えるとボーナス（例：火山セットで溶岩無効）
  • エリート敵：名前つき・付与効果持ちで光る敵。良い装備を落としやすい
  • 深さ51以降のエンドレス「深淵」：クリア後のやり込み。到達階を記録

9-2. 戦闘の手触り

  • 属性の組み合わせ反応：凍った敵を炎で叩くと「蒸気爆発」、砂で目つぶし中に会心が出やすい など
  • 武器系統ごとの必殺：短剣は連続突き、斧は大回転など、フルスイング以外の見せ場
  • ジャストガード・ジャスト回避：直前の入力でスローモーション＋反撃ボーナス
  • 敵が落とす武器を拾ってその場で使う（耐久つき）。原案の「周囲の物を使う」の発展
  • コンボ評価（C〜S）でゴールドや経験値にボーナス

9-3. 物語と世界観

  • ミオとの約束イベント：ダンジョンを進めるたびに町の会話が変わり、クレープの約束へつながる
  • 魔界の住人：ダンジョン内の休憩部屋にいる、戦わないモンスターとの会話（原案の「魔界にも暮らしがある」）
  • 相棒の記憶のかけら：各ボスが落とし、集めると相棒の正体と神界の話が明かされる（TRUEルートの条件）
  • 空のひびの変化：攻略が進むと町の空のひびが広がる／閉じる。プレイの結果が景色に残る

9-4. 遊びやすさ・続ける理由

  • モンスター図鑑・装備図鑑、実績、プレイ記録（倒した数・最大コンボ）
  • スマホの振動（ヒット時・ボスの叩きつけ）、ボタン配置のカスタマイズ
  • デイリーダンジョン（日替わりのシードで全員同じ階を遊ぶ）
